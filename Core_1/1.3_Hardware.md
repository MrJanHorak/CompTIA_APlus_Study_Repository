## Motherboards

The motherboard is the main circuit board that connects all system components.

### Form Factors

| Form Factor   | Dimensions   | Common Use                     |
| ------------- | ------------ | ------------------------------ |
| **ATX**       | 305 × 244 mm | Full desktop towers            |
| **Micro-ATX** | 244 × 244 mm | Mid-range and budget desktops  |
| **Mini-ITX**  | 170 × 170 mm | Small form factor (SFF) builds |

> Smaller form factors are generally less expensive and take up less space, but offer fewer expansion slots (PCIe, RAM slots).

### Key Motherboard Components

| Component               | Description                                                            |
| ----------------------- | ---------------------------------------------------------------------- |
| **CPU Socket**          | Physical interface for the processor; LGA (Intel) or AM4/AM5 (AMD)     |
| **RAM Slots (DIMM)**    | Typically 2 or 4 slots; support dual-channel if paired                 |
| **PCIe Slots**          | Expansion card interface; PCIe x16 for GPU, x1 for NICs/sound cards    |
| **Chipset**             | Controls communication between CPU, RAM, and peripherals               |
| **CMOS Battery**        | CR2032 coin cell; maintains BIOS/UEFI settings and the real-time clock |
| **SATA Ports**          | Connect hard drives and optical drives (typically 4–6 ports)           |
| **M.2 Slots**           | High-speed NVMe or SATA SSDs; compact form factor                      |
| **USB Headers**         | Connect front-panel USB ports                                          |
| **Front Panel Headers** | Power button, reset button, HDD activity LED, speaker                  |

### BIOS vs UEFI

| Feature              | BIOS (Legacy)    | UEFI (Modern)                              |
| -------------------- | ---------------- | ------------------------------------------ |
| **Interface**        | Text-only        | Graphical, mouse support                   |
| **Boot disk size**   | Up to 2 TB (MBR) | Over 2 TB (GPT)                            |
| **Boot speed**       | Slower POST      | Fast boot / Secure Boot                    |
| **Partition tables** | MBR              | GPT                                        |
| **Secure Boot**      | Not supported    | Supported — verifies bootloader signatures |
| **Architecture**     | 16-bit           | 32/64-bit                                  |

**Secure Boot** prevents unauthorized operating systems and bootkit malware from loading during startup. Windows 11 requires UEFI firmware with Secure Boot capability.

## CPUs

The **Central Processing Unit (CPU)** is the primary processing component of a system.

### Key CPU Concepts

| Term                                | Description                                                               |
| ----------------------------------- | ------------------------------------------------------------------------- |
| **Clock Speed (GHz)**               | Number of cycles per second; higher = faster per-core performance         |
| **Cores**                           | Independent processing units within a single CPU die                      |
| **Threads (Hyper-Threading / SMT)** | Each core can handle multiple threads simultaneously (Intel HT / AMD SMT) |
| **Cache (L1/L2/L3)**                | On-chip memory for frequently accessed data; L1 is fastest and smallest   |
| **TDP (Thermal Design Power)**      | Maximum heat the CPU is expected to produce; informs cooler selection     |
| **32-bit vs 64-bit**                | 64-bit CPUs handle more RAM and larger data; Windows 11 requires a compatible 64-bit CPU; Windows 10 also had 32-bit editions |

### CPU Socket Examples

| Manufacturer | Socket   | Generation                        |
| ------------ | -------- | --------------------------------- |
| Intel        | LGA 1700 | Desktop Core 12th/13th/14th generation; check BIOS support |
| Intel        | LGA 1851 | Core Ultra desktop Series 2 (Arrow Lake) |
| AMD          | AM4      | Ryzen 1000–5000 series            |
| AMD          | AM5      | Ryzen 7000 series and beyond      |

> **Exam Tip:** CPUs and sockets are not interchangeable across manufacturers or across socket generations. A CPU must be physically and electrically compatible with its motherboard.

---

> Socket examples: [Intel desktop Core 14th generation](https://www.intel.com/content/www/us/en/support/articles/000096847/processors.html) and [Core Ultra desktop Series 2](https://www.intel.com/content/www/us/en/support/articles/000099723/processors.html). A matching socket alone does not guarantee chipset or BIOS support.

## RAM

**RAM (Random Access Memory)** is volatile memory — all data is lost when power is removed.

### Desktop RAM (DIMM)

| Type     | Pin Count    | Key Notes                                                  |
| -------- | ------------ | ---------------------------------------------------------- |
| DDR      | 184 pins     | Legacy                                                     |
| DDR2     | 240 pins     | Faster than DDR; legacy                                    |
| DDR3     | 240 pins     | Lower voltage than DDR2                                    |
| **DDR4** | **288 pins** | Current mainstream standard                                |
| **DDR5** | **288 pins** | Newer standard; higher speeds; integrated power management |

> DDR3 and DDR4 both have 240/288 pins respectively, but their notch position is **different** — they are physically incompatible despite similar pin counts.

### Laptop RAM (SODIMM)

| Type              | Pin Count    |
| ----------------- | ------------ |
| DDR / DDR2 SODIMM | 200 pins     |
| DDR3 SODIMM       | 204 pins     |
| **DDR4 SODIMM**   | **260 pins** |
| DDR5 SODIMM       | 262 pins     |

### RAM Characteristics

| Feature                         | Description                                                                    |
| ------------------------------- | ------------------------------------------------------------------------------ |
| **Single-Channel**              | One RAM stick or non-paired configuration                                      |
| **Dual-Channel**                | Two matched sticks in paired slots; doubles memory bandwidth                   |
| **ECC (Error-Correcting Code)** | Detects and corrects single-bit memory errors; used in servers/workstations    |
| **Registered (RDIMM)**          | Additional register buffers; used in servers for large RAM capacities          |
| **XMP/EXPO**                    | Intel/AMD overclocking profiles; enables rated speeds above the JEDEC standard |

## Storage Technologies

### HDD (Hard Disk Drive)

- **Mechanism:** Rotating magnetic platters with read/write heads
- **Speed:** Typically 5400 or 7200 RPM; server drives up to 15,000 RPM
- **Interface:** SATA (most common), SAS (enterprise)
- **Advantage:** Low cost per GB for large capacities
- **Disadvantage:** Slower than SSD; vulnerable to shock damage

### SSD (Solid State Drive)

- **Mechanism:** NAND flash memory cells; no moving parts
- **Faster, quieter, more shock-resistant** than HDDs
- **Higher cost per GB** than HDDs

#### SSD Interfaces

| Interface       | Form Factor      | Speed             | Notes                                           |
| --------------- | ---------------- | ----------------- | ----------------------------------------------- |
| **SATA III**    | 2.5" or M.2      | ~600 MB/s         | Slower; backward compatible with HDD SATA ports |
| **NVMe (PCIe)** | M.2 or PCIe card | 3,500–7,000+ MB/s | Much faster; connects directly to PCIe bus      |

#### M.2 Form Factors

M.2 is a physical slot standard — it does **not** define the protocol. An M.2 slot can support either SATA or NVMe.

| Key Notch   | Protocol Supported      |
| ----------- | ----------------------- |
| **M key**   | NVMe (PCIe) and/or SATA |
| **B key** | SATA or PCIe (up to x2), depending on the device |
| **B+M key** | Fits compatible B/M sockets; protocol support must match; PCIe up to x2 |

> **Common M.2 lengths:** 2242, 2260, **2280** (most common), 22110

> Keying establishes mechanical fit, not universal compatibility. Match the SSD's SATA/PCIe protocol, lane count and physical length to the motherboard manual. Source: [Kingston M.2 FAQ](https://www.kingston.com/en/ssd/ssd-faq).

## RAID Arrays

**RAID (Redundant Array of Independent/Inexpensive Disks)** combines multiple physical drives for performance, redundancy, or both.

| RAID Level  | Function                    | Minimum Disks | Fault Tolerance | Notes                                                        |
| ----------- | --------------------------- | ------------- | --------------- | ------------------------------------------------------------ |
| **RAID 0**  | Striping                    | 2             | **None**        | Max performance; one drive failure = total data loss         |
| **RAID 1**  | Mirroring                   | 2             | **1 disk**      | Exact copy of all data on both drives                        |
| **RAID 5**  | Striping with parity        | 3             | **1 disk**      | Balances performance and redundancy; most popular            |
| **RAID 6**  | Striping with double parity | 4             | **2 disks**     | More resilient than RAID 5 for large arrays                  |
| **RAID 10** | Mirrored stripes            | 4             | **1 guaranteed; more only in different mirror pairs**   | High performance + redundancy; expensive (50% capacity used) |

> **Exam Tip:** RAID is **not** a backup. RAID 1 and RAID 5 protect against drive failure but cannot protect against accidental deletion, ransomware, or fire/flood. Always follow the **3-2-1 backup rule:** 3 copies, 2 different media, 1 off-site.

## Power Supplies

The **PSU (Power Supply Unit)** converts AC power to the DC voltages required by components.

### Voltage Rails

| Voltage | Primary Use                               |
| ------- | ----------------------------------------- |
| +3.3V   | RAM, motherboard logic                    |
| +5V     | USB ports, SATA data, legacy drives       |
| +12V    | CPU, GPU, motors (HDDs, fans)             |
| -12V    | Legacy serial ports (minimal draw)        |
| +5VSB   | Standby power (wake-on-LAN, USB charging) |

### PSU Form Factors

| Form Factor       | Use                                        |
| ----------------- | ------------------------------------------ |
| **ATX**           | Standard desktop                           |
| **SFX / TFX**     | Small form factor cases                    |
| **Redundant PSU** | Enterprise servers — dual PSU for failover |

### PSU Efficiency (80 PLUS Ratings)

| Rating   | Minimum Efficiency |
| -------- | ------------------ |
| 80 PLUS  | 80%                |
| Bronze   | 82–85%             |
| Silver   | 85–88%             |
| Gold     | 87–90%             |
| Platinum | 90–92%             |
| Titanium | 90–94%             |

### Main Power Connectors

| Connector              | Description                    |
| ---------------------- | ------------------------------ |
| **24-pin ATX**         | Main motherboard power         |
| **8-pin EPS (4+4)**    | CPU power                      |
| **6-pin / 8-pin PCIe** | GPU power                      |
| **SATA power**         | Drives and some fans           |
| **Molex (4-pin)**      | Legacy drives, some fans/pumps |

## Cooling and Thermal Management

| Method                   | Description                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------ |
| **Air Cooling**          | Heatsink + fan; most common; adequate for most workloads                             |
| **Liquid Cooling (AIO)** | All-in-one closed-loop; quieter; better peak performance for high-TDP CPUs           |
| **Custom Loop**          | DIY water cooling; highest performance; complex maintenance                          |
| **Thermal Paste**        | Applied between CPU die and heatsink to eliminate air gaps and improve heat transfer |
| **Case Airflow**         | Positive pressure (more intake fans) vs negative pressure (more exhaust fans)        |
| **Chassis Fan Headers**  | Connected to motherboard; speed controlled by PWM or DC voltage                      |

> **Common issue:** Unexpected shutdowns under load can indicate thermal or power faults; check cooling and power requirements. A burning smell requires immediate shutdown and disconnection from power. Inspect only after it is safe and replace damaged components. Do not open a PSU.

### Display Technologies

| Technology    | Notes                                                   |
| ------------- | ------------------------------------------------------- |
| **LCD (IPS)** | Wide viewing angles; accurate color; common in monitors |
| **LCD (TN)**  | Fast response time; narrow viewing angle                |

| **OLED**      | True black; exceptional contrast; possible burn-in      |
| **LED**       | Often refers to LED-backlit LCD displays                |

### Display Connectors

| Connector               | Signal Type    | Notes                                                                  |

| **VGA (D-Sub 15-pin)**  | Analog         | Legacy; no audio                                                       |
| **DVI**                 | Digital/Analog | Several variants (DVI-D, DVI-A, DVI-I); no audio                       |

## Printers and Imaging Devices

### Printer Types

| Type                    | Technology           | Speed  | Cost per Page     | Use Case               |
| ----------------------- | -------------------- | ------ | ----------------- | ---------------------- |
| **Laser**               | Toner + fuser drum   | Fast   | Low (high-volume) | Office documents       |
| **Inkjet**              | Liquid ink nozzles   | Medium | High (low-volume) | Photos, color graphics |
| **Thermal**             | Heat-sensitive paper | Fast   | Very low          | Receipts, labels       |
| **Impact (Dot Matrix)** | Pin strikes ribbon   | Slow   | Very low          | Multi-part forms       |

### Laser Printer Process (7 Steps)

1. **Processing** — Image data is sent from computer to printer memory
2. **Charging** — Drum surface is coated with a uniform negative charge
3. **Exposing** — Laser beam neutralizes charge in the areas to be printed
4. **Developing** — Toner is attracted to the discharged (exposed) areas
5. **Transferring** — Toner is transferred from drum to paper
6. **Fusing** — Heat and pressure bond toner permanently to the paper
7. **Cleaning** — Residual toner is cleared from the drum

> **Mnemonic:** _Please Call Every Dad To Fix Cars_ (Processing, Charging, Exposing, Developing, Transferring, Fusing, Cleaning)

### Printer Interfaces

| Interface            | Notes                            |
| -------------------- | -------------------------------- |
| USB                  | Most common for local printers   |
| Ethernet             | Shared network printing          |
| Wi-Fi / Wi-Fi Direct | Wireless printing without router |
| Bluetooth            | Short-range mobile printing      |
