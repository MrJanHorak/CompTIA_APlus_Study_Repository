## The CompTIA Troubleshooting Methodology

The exam frequently presents **scenario-based questions** that require applying this 6-step process. See the complete breakdown in [Cheat_Sheets/Troubleshooting_Methodology.md](../Cheat_Sheets/Troubleshooting_Methodology.md).

| Step | Action                                                                             |
| ---- | ---------------------------------------------------------------------------------- |
| 1    | **Identify the problem** — Gather information, check logs, note recent changes     |
| 2    | **Establish a theory** — Question the obvious; start with the simplest explanation |
| 3    | **Test the theory** — Change one variable at a time to confirm or refute           |
| 4    | **Establish a plan** — Design a fix with risk assessment; plan a rollback          |
| 5    | **Implement and verify** — Apply the fix; confirm resolution; check for new issues |
| 6    | **Document findings** — Record what was wrong, what was done, and the outcome      |

> **Key principle:** Change only **one variable at a time** when testing. Changing multiple components simultaneously makes it impossible to identify the actual root cause.

## Troubleshooting PC Hardware

### POST and Boot Issues

**POST (Power-On Self-Test)** runs at startup to verify critical hardware.

| Symptom                            | Likely Cause                               | Action                                  |
| ---------------------------------- | ------------------------------------------ | --------------------------------------- |
| No power at all                    | Dead PSU, faulty power cable, surge damage | Test PSU; check connections             |
| POST beep codes                    | Hardware failure (RAM, GPU, CPU)           | Look up beep code in motherboard manual |
| Continuous reboot loop             | Failed OS, faulty RAM, overheating         | Boot to recovery; run memory test       |
| "No bootable device"               | Boot order wrong, dead drive, no OS        | Check BIOS boot order; test drive       |
| BIOS settings reset after shutdown | Dead CMOS battery                          | Replace CR2032 coin cell battery        |
| System runs but no display         | Loose GPU, failed display, wrong input     | Reseat GPU; try onboard video           |

### RAM Issues

| Symptom                            | Likely Cause                               |
| ---------------------------------- | ------------------------------------------ |
| System does not POST; beep codes   | Unseated or incompatible RAM               |
| Random BSOD (Blue Screen of Death) | Faulty RAM module                          |
| System only uses partial RAM       | One stick failed; wrong slot configuration |
| BSODs only under heavy load        | Overheating RAM; marginal voltage          |

**Diagnostic tools:**

- **Windows Memory Diagnostic** — Built into Windows; runs on next boot
- **MemTest86** — Bootable standalone RAM tester; more thorough

### Power Issues

| Symptom                                | Likely Cause                                              |
| -------------------------------------- | --------------------------------------------------------- |
| System shuts down under load           | PSU under-rated for the power demand; overheating         |
| Burning smell                          | Capacitor failure (motherboard/PSU)                       |
| Random unexpected shutdowns            | Thermal throttling; PSU failing                           |
| Computer will not power on; LED is lit | Power button issue; shorting the front panel pins to test |

## Troubleshooting Storage Devices

| Symptom                        | Likely Cause                                | Action                                      |
| ------------------------------ | ------------------------------------------- | ------------------------------------------- |
| Drive not detected in BIOS     | Loose SATA/power cable, failed drive        | Reseat cables; try different SATA port      |
| Slow read/write performance    | Drive near capacity; failing HDD            | Check drive health with **CrystalDiskInfo** |
| Clicking sounds from drive     | **Imminent HDD failure ("click of death")** | Back up immediately; replace drive          |
| `S.M.A.R.T. error` at boot     | Drive reporting internal errors             | Replace drive; restore from backup          |
| "Insert disk" error on startup | Boot order points to empty optical drive    | Fix BIOS boot order                         |
| RAID array degraded            | One drive has failed                        | Replace failed drive; rebuild array         |

### Drive Health Tools

- **S.M.A.R.T. (Self-Monitoring, Analysis and Reporting Technology):** Built into drives; accessed via BIOS or software
- **CrystalDiskInfo:** Free Windows tool showing S.M.A.R.T. health status
- **chkdsk (Windows):** Scans for filesystem errors; can recover some corrupted files
- **fsck (Linux):** Equivalent filesystem check for Linux volumes

## Troubleshooting Video and Display Issues

| Symptom                        | Likely Cause                                                 | Action                                                  |
| ------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------- |
| No display at all              | Loose cable, wrong input, dead GPU                           | Check cables; verify display input source               |
| Flickering display             | Loose video cable; dying backlight                           | Reseat cable; test with another monitor                 |
| Fuzzy / blurry image on LCD    | **Incorrect resolution** or using an analog (VGA) connection | Set native resolution; use digital connection (HDMI/DP) |
| Dead pixels                    | Physical defect in panel                                     | Pixel-stuck test tools; check warranty                  |
| Display too dim                | Backlight failing; brightness setting                        | Increase brightness; test with external monitor         |
| "Ghosting" or motion blur      | Response time too high for the refresh rate                  | Enable overdrive in monitor OSD                         |
| VGA shows artifacts/distortion | Bent pins or analog signal degradation                       | Use a digital cable; inspect connector                  |
| Burn-in (OLED/Plasma)          | Static image displayed for extended period                   | Screensaver; vary content                               |

## Troubleshooting Mobile Devices

| Symptom                      | Likely Cause                                                      | Action                                                     |
| ---------------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------- |
| Battery drains quickly       | Background apps, aging battery, high screen brightness            | Check app battery usage; calibrate or replace battery      |
| Device overheating           | Intensive apps, poor ventilation, faulty battery                  | Check for runaway processes; stop charging while in a case |
| Touchscreen unresponsive     | Screen protector interference, digitizer failure, software freeze | Remove screen protector; force restart                     |
| Wi-Fi drops frequently       | Distance from AP; 2.4 GHz congestion; DHCP issues                 | Move closer; switch bands; forget and rejoin               |
| Cannot make calls            | SIM not seated; carrier issue; airplane mode                      | Reseat SIM; check carrier signal; disable airplane mode    |
| Device runs slowly           | Storage near full; background processes; old OS                   | Free up storage; restart; update OS                        |
| `No service` on a new device | eSIM or SIM not provisioned                                       | Contact carrier to provision the SIM/eSIM profile          |

## Troubleshooting Network Connectivity

### Systematic Approach

Work from the **physical layer up**:

1. Physical — is the cable connected? Is the link light on?
2. IP configuration — does the device have a valid IP address?
3. Local connectivity — can the device reach the gateway?
4. External connectivity — can the device reach the internet?

### Key Diagnostic Commands

| Command                                    | Purpose                                                              |
| ------------------------------------------ | -------------------------------------------------------------------- |
| `ipconfig` (Windows) / `ip addr` (Linux)   | Show IP address, subnet mask, default gateway                        |
| `ping 127.0.0.1`                           | Test local TCP/IP stack                                              |
| `ping <gateway IP>`                        | Test connectivity to the local router                                |
| `ping 8.8.8.8`                             | Test internet connectivity (bypasses DNS)                            |
| `ping google.com`                          | Test DNS resolution + internet connectivity                          |
| `tracert` (Windows) / `traceroute` (Linux) | Trace the path to a destination; identify where packets are dropping |
| `nslookup`                                 | Query DNS resolution for a domain                                    |
| `netstat`                                  | Show active network connections and open ports                       |

### Common Network Symptoms

| Symptom                              | Likely Cause                                      | Action                                                            |
| ------------------------------------ | ------------------------------------------------- | ----------------------------------------------------------------- |
| `169.254.x.x` IP address             | DHCP server unreachable (APIPA assigned)          | Check DHCP server; try `ipconfig /release` then `ipconfig /renew` |
| Can ping by IP but not hostname      | DNS failure                                       | Check DNS settings; try alternate DNS (8.8.8.8)                   |
| Intermittent connection              | Faulty cable; congested Wi-Fi channel             | Test cable; switch Wi-Fi channel                                  |
| All devices on network lose internet | ISP outage; router failure                        | Restart modem/router; contact ISP                                 |
| Connected to Wi-Fi but no internet   | Gateway issue; ISP problem                        | Test with another device; restart router                          |
| Extremely slow speeds                | Network congestion; half-duplex mismatch; malware | Check duplex settings; run malware scan                           |

## Troubleshooting Printers

| Symptom                      | Likely Cause                                      | Action                                              |
| ---------------------------- | ------------------------------------------------- | --------------------------------------------------- |
| Print job stuck in queue     | Spooler error; driver issue                       | Restart Print Spooler service; clear queue          |
| Faded or streaky laser print | Low toner; dirty drum                             | Shake/replace toner cartridge; clean drum           |
| Lines on laser print         | Scratched or dirty drum                           | Replace or clean drum unit                          |
| Smearing on laser print      | Fuser assembly failing                            | Replace fuser                                       |
| Paper jams frequently        | Wrong paper weight; worn rollers; misloaded paper | Check paper spec; clean/replace rollers             |
| Inkjet prints are streaky    | Clogged nozzles                                   | Run print head cleaning utility                     |
| Wrong colors on inkjet       | Wrong/empty cartridge                             | Check ink levels; align print head                  |
| Printer not found on network | IP address changed; printer offline               | Set static IP for printer; check network connection |

> **Restart the Print Spooler** is one of the most effective first steps for Windows print issues:
> `services.msc` → Print Spooler → Right-click → Restart

## Active Recall Questions

1. A user reports their computer keeps rebooting. It has passed POST before successfully. What are the first three things you check?
2. What does a `169.254.x.x` IP address indicate, and how do you resolve it?
3. You replace a RAM stick and the system no longer boots. What is the most likely cause?
4. A hard drive is making a clicking sound. What is the first action you take?
5. A laser print has smearing on all pages. Which component is failing?
6. Which command would you use to test if DNS is working correctly?
7. A user's laptop shows the correct Wi-Fi connection but cannot load any websites. How do you differentiate a DNS issue from an internet connectivity issue?
8. What tool would you use to check a drive's S.M.A.R.T. status on Windows?
