## Laptop Hardware Components

Laptops use smaller, lower-power versions of standard desktop components. The key distinction is form factor and replaceability.

### Commonly Replaced Laptop Components

| Component                    | Notes                                                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Battery**                  | Most modern laptops use integrated lithium-polymer (Li-Po) batteries. Replacement requires partial disassembly.     |
| **RAM (SODIMM)**             | Small Outline DIMM — physically smaller than desktop DIMMs. Not all laptops allow RAM upgrades (some are soldered). |
| **Storage (SSD/HDD)**        | Most modern laptops use M.2 NVMe SSDs. Older models may use 2.5" SATA drives.                                       |
| **Keyboard**                 | Usually attached via a ribbon cable. Replacement is a common field task.                                            |
| **Touchpad**                 | Connects via ribbon cable; rarely replaced independently.                                                           |
| **Wireless Card (Wi-Fi/BT)** | Usually an M.2 or mini-PCIe card. Accessible under a service panel.                                                 |
| **Optical Drive**            | Less common in modern laptops; mostly legacy hardware.                                                              |
| **DC Jack**                  | The power charging connector; a frequent point of failure from physical stress.                                     |
| **Speaker**                  | Connected by thin cables; accessible after removing the bottom panel.                                               |

### RAM Form Factors (Mobile)

| Generation        | Pin Count | Notes                             |
| ----------------- | --------- | --------------------------------- |
| DDR / DDR2 SODIMM | 200 pins  | Legacy                            |
| DDR3 SODIMM       | 204 pins  | Common in older laptops           |
| DDR4 SODIMM       | 260 pins  | Current standard for most laptops |
| DDR5 SODIMM       | 262 pins  | Emerging in newer platforms       |

> **Exam Tip:** Desktop and laptop RAM are not interchangeable. SODIMMs and DIMMs have different pin counts and physical notch positions.

## Laptop Displays

| Technology    | Characteristics                                                   |
| ------------- | ----------------------------------------------------------------- |
| **LCD (TN)**  | Fast response times; poor viewing angles; lower cost              |
| **LCD (IPS)** | Wide viewing angles; accurate colors; common in modern laptops    |
| **OLED**      | True blacks; high contrast; can suffer burn-in                    |
| **Inverter**  | Powers CCFL backlights in older displays; a replaceable component |
| **Digitizer** | The touch-sensitive layer on touchscreen laptops and tablets      |

**Display connections (internal):**

- **LVDS (Low-Voltage Differential Signaling):** Older standard
- **eDP (Embedded DisplayPort):** Current standard for internal panels

## Mobile Device Types

| Device Type               | Key Characteristics                                                 |
| ------------------------- | ------------------------------------------------------------------- |
| **Laptop**                | Full OS, clamshell design, replaceable components                   |
| **Tablet**                | Touch-first interface, often ARM-based, limited repairability       |
| **Smartphone**            | Cellular connectivity, GPS, NFC, biometric sensors                  |
| **E-reader**              | E-ink display, long battery life, limited functionality             |
| **Wearable (Smartwatch)** | Paired to smartphone, health sensors, limited standalone capability |
| **AR/VR Headsets**        | Spatial computing — a growing area in enterprise support            |

## Mobile Connectivity

### Wireless Standards

| Standard              | Frequency           | Max Speed (Theoretical) | Notes                     |
| --------------------- | ------------------- | ----------------------- | ------------------------- |
| 802.11a               | 5 GHz               | 54 Mbps                 | Legacy                    |
| 802.11b               | 2.4 GHz             | 11 Mbps                 | Legacy                    |
| 802.11g               | 2.4 GHz             | 54 Mbps                 | Legacy                    |
| 802.11n (Wi-Fi 4)     | 2.4 / 5 GHz         | 600 Mbps                | Dual-band                 |
| 802.11ac (Wi-Fi 5)    | 5 GHz               | 3.5 Gbps                | MU-MIMO                   |
| 802.11ax (Wi-Fi 6/6E) | 2.4 / 5 / **6 GHz** | 9.6 Gbps                | OFDMA; 6E adds 6 GHz band |

> **v15 Update:** Wi-Fi 6E is explicitly tested in the 220-1201 objectives. Know that the 6 GHz band reduces interference in dense environments but has shorter range than 5 GHz.

### Short-Range Connectivity

| Technology              | Range         | Use Case                                         |
| ----------------------- | ------------- | ------------------------------------------------ |
| **Bluetooth**           | ~10 m         | Peripherals, audio, file transfer                |
| **NFC**                 | < 20 cm       | Contactless payments, device pairing             |
| **IR (Infrared)**       | Line of sight | Remote controls (legacy)                         |
| **Hotspot / Tethering** | Varies        | Share cellular data via Wi-Fi, USB, or Bluetooth |

### Cellular Standards

| Generation | Notes                                              |
| ---------- | -------------------------------------------------- |
| 3G         | HSPA, UMTS — largely deprecated                    |
| 4G / LTE   | Current standard; widespread coverage              |
| 5G         | Sub-6 GHz and mmWave; higher speeds, lower latency |

## Mobile Device Management (MDM)

MDM platforms allow organizations to remotely configure, monitor, and secure mobile devices.

### Key MDM Functions

| Function                   | Description                                                                     |
| -------------------------- | ------------------------------------------------------------------------------- |
| **Remote Wipe**            | Erase all data on a lost or stolen device                                       |
| **Passcode Enforcement**   | Require a PIN or biometric lock                                                 |
| **Encryption Enforcement** | Mandate full-disk encryption                                                    |
| **App Management (MAM)**   | Control which applications can be installed                                     |
| **Profile Deployment**     | Push Wi-Fi, VPN, and email configurations                                       |
| **Geofencing**             | Trigger actions based on device location                                        |
| **BYOD Policies**          | Define security requirements for personal devices accessing corporate resources |

> **v15 Update:** MDM configuration is an expanded objective in 220-1201, reflecting the corporate shift to remote and hybrid work environments. Expect scenario-based questions about enrolling a device and applying a security policy.

## eSIM Technology

> **v15 Update:** eSIM is new in the 220-1201 objectives.

An **eSIM (Embedded SIM)** is a programmable SIM chip soldered directly onto the device motherboard.

| Feature               | Physical SIM                           | eSIM                                          |
| --------------------- | -------------------------------------- | --------------------------------------------- |
| **Form**              | Removable card (nano, micro, standard) | Embedded chip                                 |
| **Carrier switching** | Requires new physical card             | Software-based, instant                       |
| **Dual SIM**          | Requires two physical slots            | One eSIM + one physical, or two eSIM profiles |
| **Corporate use**     | MDM can't provision the SIM            | MDM can remotely provision eSIM profiles      |
| **Repairability**     | Swappable                              | Cannot be replaced independently              |

## Accessories and Ports

### Common Laptop / Mobile Ports

| Port                    | Description                                                                |
| ----------------------- | -------------------------------------------------------------------------- |
| **USB-A**               | Standard rectangular USB connector                                         |
| **USB-C**               | Reversible; supports USB 3.x, Thunderbolt, DisplayPort, and Power Delivery |
| **Thunderbolt 3 / 4**   | Uses USB-C connector; up to 40 Gbps; supports daisy-chaining               |
| **HDMI**                | Digital audio/video output                                                 |
| **Mini DisplayPort**    | Common on older Apple and Microsoft devices                                |
| **SD Card Reader**      | Reads SD/microSD storage cards                                             |
| **3.5mm Audio Jack**    | Headphone/microphone combo or separate jacks                               |
| **RJ-45 (via adapter)** | Wired Ethernet; often requires a dongle on thin laptops                    |

### Docking Stations

A **docking station** extends a laptop's connectivity by providing multiple ports (USB, Ethernet, display outputs, audio) through a single connection — typically USB-C or Thunderbolt. This is a standard enterprise tool for hybrid workers.
