## Troubleshooting Windows OS Issues

### Applying the Troubleshooting Methodology

Always follow the 6-step process: Identify → Theory → Test → Plan → Implement/Verify → Document. See [Cheat_Sheets/Troubleshooting_Methodology.md](../Cheat_Sheets/Troubleshooting_Methodology.md).

### Common Windows Symptoms and Solutions

| Symptom                                 | Likely Cause                                                        | Resolution                                                                    |
| --------------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **Blue Screen of Death (BSOD)**         | Driver failure, RAM fault, corrupted system files, hardware issue   | Note stop code; run `sfc /scannow`; check Event Viewer; test RAM              |
| **System runs slowly**                  | Insufficient RAM; high disk I/O; malware; too many startup programs | Task Manager; disable startup apps; check disk health; run malware scan       |
| **Frequent unexpected shutdowns**       | Overheating; PSU instability; OS corruption                         | Check thermals; test PSU; run `sfc`; review Event Viewer                      |
| **Application crashes**                 | Outdated app or driver; corrupted install; incompatible update      | Update or reinstall app; roll back driver; check Event Viewer Application log |
| **System will not update**              | Windows Update service issue; disk space; corrupted update files    | Reset Windows Update components; free disk space; run `DISM`                  |
| **System clock resets**                 | Dead CMOS battery                                                   | Replace CR2032 battery on motherboard                                         |
| **Desktop icons or taskbar missing**    | Explorer.exe crash                                                  | Open Task Manager → Run → `explorer.exe`                                      |
| **Spinning wheel / high disk activity** | Disk thrashing from low RAM; SuperFetch; malware                    | Add RAM; disable SuperFetch; scan for malware                                 |
| **User profile fails to load**          | Corrupted profile                                                   | Log in as admin; copy data from corrupted profile; create new profile         |

### BSOD Stop Codes

| Stop Code                     | Common Meaning                             |
| ----------------------------- | ------------------------------------------ |
| `IRQL_NOT_LESS_OR_EQUAL`      | Driver or RAM issue                        |
| `PAGE_FAULT_IN_NONPAGED_AREA` | Bad RAM or driver accessing invalid memory |
| `SYSTEM_SERVICE_EXCEPTION`    | Driver or kernel-level software error      |
| `CRITICAL_PROCESS_DIED`       | Core Windows process crashed               |
| `NTFS_FILE_SYSTEM`            | File system / disk error                   |

> **Exam Tip:** You do not need to memorize all stop codes but should recognize that BSODs point toward hardware or driver failures rather than user-space application issues.

## Windows Boot Process and Recovery

### UEFI/BIOS Boot Sequence

1. **POST** — Hardware self-test
2. **UEFI/BIOS** — Reads boot order; locates bootable device
3. **Bootloader (Windows Boot Manager)** — Stored in EFI System Partition (ESP); loads `winload.efi`
4. **Windows Kernel loads** — `ntoskrnl.exe`
5. **Session Manager** — `smss.exe` initializes the user session
6. **Winlogon** — Presents the login screen

### Boot Issues and Recovery Tools

| Issue                               | Recovery Tool                                                           |
| ----------------------------------- | ----------------------------------------------------------------------- |
| **Boot configuration corrupted**    | `bootrec /rebuildbcd` from WinRE                                        |
| **MBR damaged**                     | `bootrec /fixmbr`                                                       |
| **Boot sector damaged**             | `bootrec /fixboot`                                                      |
| **Recent update broke boot**        | Startup Repair (WinRE)                                                  |
| **Driver or software causing loop** | Safe Mode; Device Manager to roll back driver                           |
| **OS files corrupted**              | `sfc /scannow` (online) or `DISM /online /cleanup-image /restorehealth` |

### Accessing Windows Recovery Environment (WinRE)

- During boot, press **F8** (may need to enable via `bcdedit /set {default} recoveryenabled Yes`)
- Boot from Windows installation media and select "Repair your computer"
- Hold **Shift** while clicking Restart in Windows

### Safe Mode Options

| Mode                              | When to Use                                                             |
| --------------------------------- | ----------------------------------------------------------------------- |
| **Safe Mode**                     | Minimal drivers and services; diagnose driver issues                    |
| **Safe Mode with Networking**     | Same as Safe Mode but with network access; useful for downloading tools |
| **Safe Mode with Command Prompt** | CLI only; for advanced recovery                                         |

### System Restore

- Creates restore points before significant system changes (driver installs, updates)
- Reverts Windows system files and registry to a prior state
- Does **not** affect user files
- Access: System Properties → System Protection → System Restore

## Troubleshooting Application Issues

| Symptom                        | Action                                                                                   |
| ------------------------------ | ---------------------------------------------------------------------------------------- |
| App fails to install           | Check compatibility (32-bit vs 64-bit); verify system requirements; run as administrator |
| App crashes on launch          | Reinstall; check Event Viewer Application log for error codes                            |
| App runs slowly                | Check memory and CPU usage in Task Manager; update app                                   |
| Error: "missing DLL"           | Reinstall the application; download Visual C++ Redistributables or .NET runtime          |
| App not responding             | Task Manager → End Task; or `taskkill /im appname.exe /f`                                |
| License error                  | Verify license key; check internet connectivity for license activation                   |
| Compatibility issues (old app) | Run in compatibility mode (right-click → Properties → Compatibility tab)                 |

### Windows 32-bit vs 64-bit Applications

- 64-bit apps install to: `C:\Program Files\`
- 32-bit apps install to: `C:\Program Files (x86)\`
- A 64-bit OS can run 32-bit apps; a 32-bit OS **cannot** run 64-bit apps

## Troubleshooting Security Issues

| Symptom                                          | Likely Cause                                  | Action                                                                               |
| ------------------------------------------------ | --------------------------------------------- | ------------------------------------------------------------------------------------ |
| Browser homepage changed                         | Browser hijacker / adware                     | Run anti-malware scan; reset browser settings                                        |
| Unexpected pop-ups everywhere                    | Adware; malicious browser extension           | Remove extensions; run Malwarebytes                                                  |
| Antivirus disabled without user action           | Rootkit or malware killing AV                 | Boot to offline scanner; run full system scan                                        |
| Unknown processes using high CPU                 | Cryptominer; botnet agent                     | Task Manager; research process name; run scan                                        |
| Sluggish performance after clicking unknown link | Malware installed via social engineering      | Disconnect network; run full scan; review Event Viewer                               |
| Files encrypted with ransom note                 | Ransomware                                    | Disconnect network; DO NOT PAY without consulting security team; restore from backup |
| Account locked out                               | Brute-force attack or compromised credentials | Reset password; enable MFA; review sign-in logs                                      |
| Unexpected data usage (mobile)                   | Malware exfiltrating data                     | Check data usage per app; factory reset if needed                                    |

### Ransomware Incident Response

1. **Isolate the device** — disconnect from all networks immediately
2. **Identify the ransomware variant** — ID Ransomware website can help
3. **Do not pay the ransom** without consulting your security team (payment does not guarantee recovery)
4. **Restore from clean backups** — the most reliable recovery method
5. **Identify and remediate the infection vector** — patch the exploited vulnerability
6. **Report** to management and, if required, to law enforcement

## Troubleshooting Mobile OS Issues

| Symptom                           | Likely Cause                                                                | Resolution                                              |
| --------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------- |
| App won't install                 | Insufficient storage; security settings; incompatible OS version            | Free space; enable sideloading; update OS               |
| App crashes immediately           | Incompatible update; corrupted install                                      | Uninstall and reinstall; check for app updates          |
| Device runs hot                   | Background apps; charging with intensive use; failing battery               | Close background apps; check battery health             |
| Device won't charge               | Dirty connector; faulty cable; failed charging IC                           | Clean port; test with known-good cable; replace battery |
| Cannot connect to corporate email | MDM profile not installed; certificate issue                                | Install MDM profile; verify server and account settings |
| Factory reset needed              | Attempt a factory reset only **after** backing up data and as a last resort | Settings → Reset → Factory Reset                        |

### iOS vs Android Key Differences (Exam Context)

| Feature            | iOS (Apple)                                 | Android                            |
| ------------------ | ------------------------------------------- | ---------------------------------- |
| App source         | App Store only (unless Enterprise enrolled) | Google Play + sideloading allowed  |
| Update control     | Apple controls updates                      | OEM + carrier may delay updates    |
| Backup             | iCloud / iTunes                             | Google Backup / manufacturer cloud |
| File system access | Restricted                                  | More open                          |
| MDM enrollment     | Apple Business Manager (ABM)                | Android Enterprise                 |

## Remote Support Tools

Remote access enables technicians to diagnose and resolve issues without physical presence.

| Tool                                | Protocol/Port | Notes                                                        |
| ----------------------------------- | ------------- | ------------------------------------------------------------ |
| **Windows Remote Desktop (RDP)**    | TCP 3389      | Built-in; requires Pro edition on host                       |
| **Windows Quick Assist**            | HTTPS (443)   | Built-in Windows tool; no Pro requirement for receiving help |
| **TeamViewer**                      | TCP/UDP 5938  | Third-party; cross-platform; useful for consumer support     |
| **Remote Assistance (legacy)**      | Various       | Older Windows tool; largely replaced by Quick Assist         |
| **VNC (Virtual Network Computing)** | TCP 5900      | Open standard; cross-platform                                |
| **SSH**                             | TCP 22        | CLI remote access for Linux/macOS servers                    |

> **Security note:** Remote access tools are a top target for attackers. Ensure tools use strong authentication, are updated, and are disabled when not in use. RDP open to the internet is a critical vulnerability — use VPN or restrict with firewall rules.
