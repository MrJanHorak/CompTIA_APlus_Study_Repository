## Exam Domain Breakdown

| Domain | Topic                    | Approximate Weight |
| ------ | ------------------------ | ------------------ |
| 1.0    | Operating Systems        | 31%                |
| 2.0    | Security                 | 25%                |
| 3.0    | Software Troubleshooting | 22%                |
| 4.0    | Operational Procedures   | 22%                |

## How to Study Core 2

- **Highest priority:** Operating Systems (31%) is the largest single domain in the entire A+ curriculum. Windows command-line tools and OS features are heavily tested.
- **Security:** Malware types, authentication methods, and wireless security are frequent exam targets.
- **Scenario questions:** Core 2 has more scenario-based questions than Core 1. Practice applying the troubleshooting methodology to software and OS problems.
- **Soft skills:** Operational Procedures (Domain 4.0) tests communication, change management, and documentation — do not neglect this domain.
