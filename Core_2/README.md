## How to Study Core 2

- **Highest priority:** Operating Systems and Security each carry 28% of Core 2. Practice OS administration and security tasks alongside factual review.
- **Security:** Malware types, authentication methods, and wireless security are frequent exam targets.
- **Scenario questions:** Practice diagnosing software and OS problems from symptoms, selecting an appropriate action, and verifying the outcome.
- **Soft skills:** Operational Procedures (Domain 4.0) tests communication, change management, and documentation — do not neglect this domain.
